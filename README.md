# Quiz App

## Description

Quiz App is a Flutter-based mobile application that allows users to test their knowledge through interactive quizzes. Users can create accounts, log in securely, select quiz categories, attempt quizzes, view their scores, and receive notifications.

The application communicates with backend REST APIs to manage user authentication, retrieve quiz questions, and fetch notifications. The project demonstrates modern mobile application development practices, API integration, state management, and persistent storage using Shared Preferences.

## Features

* User Registration
* User Login
* Quiz Categories
* Dynamic Question Loading
* Score Calculation
* Result Screen
* Notification System
* API Integration
* Local Data Persistence using Shared Preferences
